## Pre-registered experiment contract

Solver: `direct-json-v1`. Prompt contains all training input/output pairs and exactly one test input, requests only a JSON output grid, and never includes the test output.

Primary metric: exact full-task accuracy. Secondary diagnostics: parse failures, calls, cache hits, input/output/total tokens and target-model runtime.

Success condition: durable per-task target-model outputs and exact score for the full frozen validation split.

Falsification: any missing task, test-output leakage, unaccounted request, scorer mismatch, or inability to obtain the target-model outputs makes the baseline incomplete.
