# ARC Prize 2026 Reconnaissance Snapshot

Checked: 2026-08-22.

## ARC-AGI-2

Official competition objective: reach strong accuracy on unseen ARC-AGI-2 reasoning tasks under Kaggle efficiency limits. The public ARC-AGI-2 dataset contains 1000 training tasks and 120 public evaluation tasks; semi-private and private evaluation sets each contain 120 calibrated tasks.

Kaggle scoring accepts two predicted outputs for each test input; a task scores if either prediction exactly matches the hidden answer. Competition evaluation notebooks run without internet and allow freely/publicly available external data and pretrained models subject to competition rules.

Prize eligibility requires open-source/reproducible solutions. Authored code/methods must be released under a permissive public-domain-style license such as CC0 or MIT-0; third-party dependencies must permit public sharing.

## Implication for this lab

- Development can use hosted Gemma as a research convenience, but final architecture must not require online inference.
- Gemma 4 hosted API model identifiers are currently `gemma-4-26b-a4b-it` and `gemma-4-31b-it`; Google publishes open weights under Apache-2.0.
- The primary scientific question is not whether Gemma can be prompted once, but how much a reproducible inference architecture can improve a fixed model under controlled cost.
